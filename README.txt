Audi Q7 Cockpit Pro - Static Publishing Package

Contents:
- index.html: complete self-contained page (HTML, CSS, JavaScript, and embedded image data).

Publish:
1. Extract this ZIP archive.
2. Upload the contents of the extracted folder to your static web host's public site directory.
3. Keep the main file named index.html so it opens as the site homepage.

No build step or package installation is required. The page uses browser localStorage for locally saved finance entries. Those entries are stored in each visitor's browser and are not automatically shared between devices or users.

For a quick local test, open index.html in a modern browser. For public deployment, use HTTPS hosting.
